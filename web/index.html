From USB to your desk

  1. Connect. Plug your E32R35T into your computer with a USB data cable. Close serial monitors or other apps using its port.
  2. Install. Choose an option above and select the USB-SERIAL CH340 device. On this project's development PC, it is COM13; yours may differ.
  3. Configure. On the CYD, open SETUP → WI-FI, then configure PropView and HamAlert. SETUP → CLOCK selects local time; CASE LIGHT selects static colors or the RGB gradient.

The flasher detects the ESP32 chip family, not the display-board model. This build is for the E32R35T layout with battery sensing on GPIO34 and red LED on GPIO22.

Connection troubleshooting

If no port appears, try another data cable or install your device vendor's CH340 driver. If automatic connection fails, hold BOOT while starting the connection, then release it after connecting. Wi-Fi setup happens on the device; this firmware does not use browser-based Improv Wi-Fi provisioning.
